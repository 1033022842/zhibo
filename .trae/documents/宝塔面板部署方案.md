# 宝塔面板安装与项目部署方案

## 目标

在云服务器 `45.194.18.42` 上安装宝塔面板，之后由你在宝塔面板内完成项目部署。

***

## 第一阶段：SSH 连接并安装宝塔面板

### 步骤 1：SSH 连接服务器

我通过 SSH 连接到服务器：

```bash
ssh root@45.194.18.42
# 密码：@#22879#$%AQ
```

### 步骤 2：安装宝塔面板

连接成功后执行宝塔官方一键安装脚本：

```bash
curl -sSO https://download.bt.cn/install/install_panel.sh && bash install_panel.sh ed8484bec
```

安装过程约 2-5 分钟，完成后终端会输出类似：

```
==================================================================
外网面板地址: http://45.194.18.42:xxxxx/xxxxxxxx
内网面板地址: http://10.x.x.x:xxxxx/xxxxxxxx
username: xxxxxxxx
password: xxxxxxxx
==================================================================
```

> **重要**：记下输出的 **外网面板地址**、**username**、**password**，这就是你登录宝塔的凭证。

### 步骤 3：放行防火墙端口

如果云服务商有安全组（如阿里云/腾讯云/华为云），需要在安全组中放行宝塔默认端口：

| 端口                 | 用途                        |
| ------------------ | ------------------------- |
| `8888`（或安装脚本输出的端口） | 宝塔面板管理入口                  |
| `80` / `443`       | Web 站点 HTTP/HTTPS         |
| `8787`             | Webman HTTP（WebSocket 管理） |
| `8788`             | WebSocket 连接              |
| `3306`             | MySQL（仅本地访问可不放行）          |
| `6379`             | Redis（仅本地访问可不放行）          |

## 第二阶段：你在宝塔面板内的操作指南

安装完成后，我无法直接操作宝塔面板，以下由你手动操作。宝塔面板提供**软件商店**一键安装，整个过程基本是点选操作。

### 步骤 4：登录宝塔并安装环境软件

1. 浏览器打开宝塔外网面板地址，用 username/password 登录
2. 首次登录会弹出推荐安装套件，选择 **LNMP**：

   * **Nginx** 最新稳定版

   * **MySQL 8.0** 或 **MySQL 5.7**

   * **PHP 8.2** 或 **PHP 8.3**

   * **phpMyAdmin**（可选，方便管理数据库）
3. 勾选 **编译安装**（更稳定），点一键安装，等待安装完成（约 10-20 分钟）

### 步骤 5：补充安装其他软件

在宝塔「软件商店」中搜索并安装：

| 软件                          | 用途                     |
| --------------------------- | ---------------------- |
| **Redis**                   | 缓存服务                   |
| **Supervisor**（或叫"进程守护管理器"） | 守护 Webman WebSocket 进程 |
| **Node.js 版本管理器**           | 用于前端构建（选 Node 20.x）    |
| **phpMyAdmin**（如未安装）        | 数据库管理                  |

### 步骤 6：配置 PHP 扩展

在宝塔「软件商店」→「PHP 8.2/8.3」→「设置」→「安装扩展」中确认以下扩展已启用：

* `fileinfo`

* `redis`

* `opcache`

* `bcmath`

* `gd`

* `mbstring`

* `pdo_mysql`

* `curl`

* `zip`

### 步骤 7：创建网站

1. 宝塔「网站」→「添加站点」
2. 域名填写：`45.194.18.42`（或你的实际域名）
3. 根目录先随便填（后续会改），PHP 版本选刚才安装的版本
4. 数据库选择「创建」，记下数据库名、用户名、密码

### 步骤 8：上传项目代码

两种方式任选：

**方式 A — 宝塔文件管理器上传（推荐）**：

1. 在本地把项目打包成 zip（排除 node\_modules、vendor、.git 等）
2. 宝塔「文件」，进入 `/www/wwwroot/`，新建目录 `douyin`
3. 上传 zip 并解压到 `/www/wwwroot/douyin/`

**方式 B — Git 拉取**：

1. 宝塔「软件商店」安装 **Git 管理器**
2. 宝塔终端中执行：

   ```bash
   cd /www/wwwroot
   git clone <你的仓库地址> douyin
   ```

### 步骤 9：配置项目站点

#### 9.1 配置 PHP 后端站点

修改刚才创建的网站配置：

1. 宝塔「网站」→ 点击站点名 →「网站目录」
2. 运行目录改为：`/www/wwwroot/douyin/php/public`
3. 「伪静态」填入 ThinkPHP 规则（宝塔通常内置了，选 `thinkphp` 即可）

#### 9.2 配置 `.env` 文件

在服务器上编辑 `/www/wwwroot/douyin/php/.env`：

```ini
APP_DEBUG = false

[DATABASE]
TYPE = mysql
HOSTNAME = 127.0.0.1
DATABASE = live_platform
USERNAME = <步骤7创建的数据库用户名>
PASSWORD = <步骤7创建的数据库密码>
HOSTPORT = 3306
PREFIX = ba_
CHARSET = utf8mb4
DEBUG = false

[REDIS]
HOST = 127.0.0.1
PORT = 6379
PASSWORD =
SELECT = 0

[JWT]
secret = <替换为一个随机长字符串>
```

### 步骤 10：安装项目依赖

在宝塔「终端」中执行：

```bash
# 1. 安装 PHP 后端依赖
cd /www/wwwroot/douyin/php
composer install --no-dev

# 2. 安装 Webman WebSocket 依赖
cd /www/wwwroot/douyin/apps/ws-webman
composer install --no-dev

# 3. 导入数据库
mysql -u<数据库用户名> -p<数据库密码> <数据库名> < /www/wwwroot/douyin/live_platform_schema.sql

# 4. 构建管理后台前端
cd /www/wwwroot/douyin/php/web
pnpm install
pnpm build
# 同步构建产物到 public 目录
cp -r dist/* ../public/

# 5. 构建 H5 用户端前端
cd /www/wwwroot/douyin/vue
pnpm install
pnpm build
```

### 步骤 11：配置 H5 前端 Nginx

宝塔「网站」→ 点击站点名 →「配置文件」，替换为以下配置：

```nginx
server
{
    listen 80;
    server_name 45.194.18.42;
    index index.html index.php index.htm;

    # H5 前端静态文件
    location / {
        root /www/wwwroot/douyin/vue/dist;
        try_files $uri $uri/ /index.html;
    }

    # API 请求转发到 PHP
    location /api/ {
        root /www/wwwroot/douyin/php/public;
        if (!-e $request_filename) {
            rewrite ^(.*)$ /api/index.php?s=$1 last;
        }
    }

    # HLS 直播流
    location /hls/ {
        alias /www/wwwroot/douyin/php/public/hls/;
    }

    # PHP 处理
    location ~ \.php(/|$) {
        root /www/wwwroot/douyin/php/public;
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_index index.php;
        include fastcgi.conf;
        include pathinfo.conf;
    }

    # WebSocket 代理
    location /ws/ {
        proxy_pass http://127.0.0.1:8788/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 86400;
    }

    # 禁止访问敏感文件
    location ~* (\.user.ini|\.htaccess|\.env$|\.project|\.git|composer\.json|composer\.lock)
    {
        return 404;
    }

    location ~ .*\.(gif|jpg|jpeg|png|bmp|swf)$
    {
        expires 30d;
    }

    location ~ .*\.(js|css)?$
    {
        expires 12h;
    }

    access_log /www/wwwlogs/45.194.18.42.log;
    error_log /www/wwwlogs/45.194.18.42.error.log;
}
```

### 步骤 12：配置 Supervisor 守护 Webman

1. 宝塔「软件商店」→「Supervisor 进程守护管理器」→「设置」→「添加守护进程」
2. 填写：

| 字段   | 值                                                                 |
| ---- | ----------------------------------------------------------------- |
| 名称   | `douyin-ws`                                                       |
| 启动用户 | `root`                                                            |
| 运行目录 | `/www/wwwroot/douyin/apps/ws-webman`                              |
| 启动命令 | `/usr/bin/php /www/wwwroot/douyin/apps/ws-webman/start.php start` |
| 进程数  | `1`                                                               |

1. 环境变量设置（可直接写在 Supervisor 配置后面，或编辑配置文件添加）：

```
environment=DB_HOST="127.0.0.1",DB_PORT="3306",DB_NAME="live_platform",DB_USER="<数据库用户名>",DB_PASSWORD="<数据库密码>",DB_CHARSET="utf8mb4",REDIS_HOST="127.0.0.1",REDIS_PORT="6379",REDIS_PASSWORD="",REDIS_DB="0"
```

1. 点击「确定」并启动守护进程

## 注意事项

1. **安全组**：务必在云服务商控制台的「安全组/防火墙」中放行 80、8888、8787、8788 端口，否则外部无法访问。
2. **`.env`** **安全**：生产环境 `.env` 不要暴露到公网，Nginx 配置中已禁 `.env` 文件访问。
3. **ffmpeg**：如果需要本地 HLS 推流（channel-worker），还需在服务器上安装 ffmpeg：

   ```bash
   # Ubuntu
   apt install ffmpeg -y
   ```
4. **域名**：建议后续绑定一个真实域名并配置 SSL 证书（宝塔提供免费 Let's Encrypt 一键申请）。
