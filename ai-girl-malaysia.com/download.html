支付网关接入手册

接入需知

数据交互说明

  1. 接口之间的签名和验签统一采用 MD5。
  2. 采用 HTTP 协议标准的 POST 方式调用接口。
  3. 字符编码采用 UTF-8 编码。
  4. 商户调用平台 API，发送的 POST 请求 Content-Type 采用 application/x-www-form-urlencoded。
  5. 商户调用平台 API，平台的响应的 Content-Type 为 application/json
  6. 商户需登录到商户后台获取到 Key（用于构造签名原文）
  7. 商户后台的 Return URL（用户支付成功后，将携带订单信息从收银台重定向到该网址）可根据商户的业务场景自行配置，不要求必须配置。
  8. 对于查询类型 API，如 查询订单接口，查询上游账单接口， 商户余额查询接口，商户补单接口 会有请求频率（Per Request/ 1 seconds）限制，商户需要合理使用查询类 API。
  9. 出金接口，查询订单接口，查询上游账单接口， 商户余额查询接口，商户补单接口 需要在商户后台配置 IP 白名单，才能正常调用。
  10. API 遵循 RESTful 设计规范，正确的 POST 请求的 HTTP 响应状态码为 201， 响应参数里的 code 字段的值为 200，错误的 POST 请求 HTTP
    响应状态码为 400， 响应参数里的 code 字段值为 400
  11. 商户技术可以在 请求头部(HTTP Header) 中配置字段 requestid ，方便在 请求日志菜单 中查看实际发送到系统的请求，解决 签名错误等常见的对接问题

数据签名

加密方式

  1. 待签字符串 = 按照顺序 ( merchant_no + params + sign_type + timestamp + Key ) ，将对应字段的值拼接组成的字符串
  2. 对待签字符串进行 MD5 加密（大小写不敏感）。

加密演示

生成待签字符串

除 sign 字段外的请求参数 json 示例：


  {
    "merchant_no": "BmQrn",
    "timestamp": 1606806265,
    "sign_type": "MD5",
    "params": "{"merchant_ref": "8WTtY", "product": "LB69z", "amount": "106", "extra": {"bank_code": "KBANK", "account_no": "urbLG"}, "language": "th_TH"}",
  }

假设商户私钥为 123456，则待签字符串为：

BmQrn{“merchant_ref”: “8WTtY”, “product”: “LB69z”, “amount”: "106", “extra”: {“bank_code”: “KBANK”, “account_no”: “urbLG”}, “language”: “th_TH”}MD51606806265123456
签名

Md5 加密后： 614fa9c3637897738a607209f94e2461

最终请求参数为

  {
    "merchant_no": "BmQrn",
    "timestamp": 1606806265,
    "sign_type": "MD5",
    "params": "{"merchant_ref": "8WTtY", "product": "LB69z", "amount": "106", "extra": {"bank_code": "KBANK", "account_no": "urbLG"}, "language": "th_TH"}",
    "sign": "614fa9c3637897738a607209f94e2461"
  }
注意事项：签名时将字符转化成字节流时指定字符集全部采用UTF-8；

      存款异步通知接口

      接口说明：

      1. 订单成功后，平台将在 2 秒内对商户后台配置的 Notify URL 发送请求通知订单成功；
      2. 平台发送的通知请求的 Content-Type 为application/x-www-form-urlencoded
      3. 商户接收到异步请求后，需要验证签名，方可提取数据；
      4. 商户端收到通知并处理完成后需返回 SUCCESS 字符串（大小写不敏感），即应答的 Content-Type 应为 text/plain;charset=utf-8，若不返回或非该字符串，平台会判定本次通知失败；
      5. 平台通知超时时间设置为 10 秒，从建立连接到商户应答时间若超过 10 秒，平台将会自动断开连接，判定本次通知失败；
      6. 通知失败后，会每隔 10 秒重试通知，最多通知 5 次；

      请求方式：POST

      1. 订单成功后，平台将在 2 秒内对商户后台配置的 Notify URL 发送请求通知订单成功；

      请求URL：https://api.star-pay.vip/api/gateway/supply

      请求方式：POST

      公共请求参数

      参数名
      必选
      类型
      说明
      merchant_no
      是
      string
      商户号
      timestamp
      是
      integer
      发送请求的 10 位时间戳
      sign_type
      是
      string
      默认为 MD5
      sign
      是
      string
      签名 MD5(merchant_no+params+sign_type+timestamp+Key)
      params
      是
      string
      业务请求参数组成的 JSON String；若接口对应的业务参数不需要字段传输，该字段的值可为空字符串

      业务请求参数 params 说明

      参数名
      必选
      类型
      说明
      action
      是
      string
      操作：callback_order： 回调订单；add_balance: 增加余额
      merchant_ref
      否
      string
      商户订单号，若 action 为 callback_order 该字段必传
      product_ref
      是
      string
      产品订单号（印度产品为 UTR）
      currency
      是
      string
      产品订单号的货币

      curl 请求示例

      
  curl --location --request POST 'https://{gateway url }' \
  --header 'Content-Type: application/x-www-form-urlencoded' \
  --data-urlencode 'merchant_no=10001' \
  --data-urlencode 'timestamp=1603092543' \
  --data-urlencode 'sign_type=MD5' \
  --data-urlencode 'params={"merchant_ref": "merchant_ref1", "product_ref": "merchant_ref2"}' \
  --data-urlencode 'sign=99ff1740febf2cca86850754600ab387'

      公共响应参数

      参数名
      类型
      说明
      code
      string
      200： 请求成功； 400：请求失败
      timestamp
      integer
      响应请求的 10 位时间戳
      message
      string
      错误消息说明，只有当 code 为 400 时，该字段才有值
      params
      string
      响应业务参数组成的 JSON String，只有当 code 为 200 时，该字段才有值

      业务响应参数 params 说明

      参数名
      类型
      说明
      merchant_ref
      string
      商户订单号
      system_ref
      string
      平台订单号
      pay_amount
      string
      实际支付金额
      amount
      string
      金额
      fee
      string
      手续费
      status
      integer
      存款订单状态：0：Unpaid；1：Paid；付款订单状态：1：Success； 2: Pending；5: Reject
      success_time
      integer
      成功支付时间（时间戳），订单未成功时，该字段值为 null
      extend_params
      string
      扩展字段
      product
      string
      产品名

      常见错误信息

      错误信息
      错误描述
      解决方案
      Invalid ip address
      无效的 IP 地址
      到商户后台设置 IP 白名单
      ErrorDetail(string=’Request was throttled. Expected available in 56 seconds.’, code=’throttled’)
      请求频率过高
      降低请求频率
      Only unpaid order can be supplied
      只有未支付的订单才能申请补单
      更换请求的订单号
      Can’t find the transaction
      交易流水查找不到
      联系客服，确认交易流水是否正确
      The transaction has been processed.
      流水已被处理
      更换为未被处理过的交易流水
      Amount does not match
      交易流水与订单金额不匹配
      交易流水与订单金额不匹配
