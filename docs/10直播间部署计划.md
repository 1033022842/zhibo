## 阶段 0：worker.py 两项改造（本地改码，先测后部）

1. **copy 推流**（`build_rtmp_command`）
   - 新增环境开关 `PUSH_COPY=1`：推流命令改 `-c:v copy -c:a copy`（预转 TS 已是目标规格，纯转封装 MPEGTS→FLV）
   - 效果：直播中 CPU≈0（当前重编码 1080p×10 需 8-12 核，4 核根本跑不动；copy 后 4 核绰绰有余）
   - 保留 `-re`、`-reconnect_at_eof 1`、`+genpts` 关键参数
   - 码率从此由**预转参数**唯一决定（解决写死 1Mbps 问题）
2. **预转缓存哈希改相对路径**（`ts_cache_path`）
   - md5 键从"绝对路径|规格"改为"素材相对路径|规格"，MEDIA_BASE_DIR 不参与哈希
   - 效果：AI 电脑（NVENC 快速预转）生成的 ts_cache 整目录上传 164 直接可用，两边 MEDIA_BASE_DIR 内目录结构一致即可
3. 预转规格按目标清晰度定（env：`TS_SCALE` / 预转 cq）：
   - 720p：`720:1280`，VBR ~3Mbps（cq 24）
   - 1080p：`1080:1920`，VBR ~5Mbps（cq 23）
4. 本地验证：改码后先在本地用样本视频跑通 预转→copy推流→SRS测试流 全链路，确认时间戳连续、EOF 重连、无花屏

## 阶段 1：素材预转与上塔

1. SMB 挂载 AI 电脑，侦查 `D:\完整视频` 结构（10 个人设目录名 / 待机视频数 / 礼物文件夹名 / 文件规格）
2. **AI 电脑跑预转**（用改造后 worker 的预转逻辑或独立脚本，NVENC）：产出 ts_cache + 记录清单（persona → 待机列表 + 礼物 keyword→文件）
3. 上传 164：`/www/wwwroot/douyin/media/{persona}/`（原片）+ ts_cache 目录
   - 注意当前带宽只有 5-10Mbps：**升带宽后再传**（1080p 素材+缓存可能 50-100G，100Mbps 下 1.5-3 小时；50M 下 3-6 小时）
   - 磁盘核对：164 剩 29G 不够则先扩盘（≥100G）
4. 备选：若不想动 AI 电脑，预转放 164 错峰跑（4 核 libx264 1080p 预转约 10-20 小时，开播前 1-2 天启动）

## 阶段 2：数据入库（SQL 执行前出清单给用户确认 + mysqldump 备份）

每房间接线（10 次）：
1. `lp_media_asset`：待机视频（persona=人设，无keywords）+ 礼物视频（persona=人设，keywords=礼物文件夹名）
2. `lp_playlist_template` + `lp_playlist_template_item`（待机播单，按 seq）
3. `lp_room` + `lp_room_binding`（persona / stream_template_id=1 / playlist_id）—— 清理旧 room1-8 绑定后启用 1-10
4. `lp_gift_keyword` 对齐：礼物文件夹名缺映射的补录（现有：比心/投喂）

## 阶段 3：worker×10 部署（164）

1. 部署 `services/channel-worker/python/`（含两项改造）到 164，python3/ffmpeg 环境检查
2. systemd 单元 ×10：`--room N`（N=1..10）、`HTTP_PORT=8130+i`、`MEDIA_BASE_DIR=/www/wwwroot/douyin/media`、`RTMP_BASE=rtmp://127.0.0.1:1935`、`PUSH_COPY=1`、DB/REDIS 指本机
3. **停 AI 电脑旧 room1 推流**（`schtasks` 停 AIWorkerRoom1，避免双推；AI 电脑 worker 环境本身不动）
4. 看日志逐路确认「默认播单 N 个 TS 就绪」「[RTMP] 已上线」

## 阶段 4：Bunny CDN 接入

1. Pull Zone：回源 `https://hsl.lat`，缓存规则 `*.m3u8` → 1-3 秒、`*.ts` → 长缓存（详见附录A）
2. 164 php `.env` 追加 `HLS_CDN_DOMAIN = https://<zone>.b-cdn.net`，清 ThinkPHP 缓存
3. 验证 `/api/v1/rooms/N` 返回的 `hls_url` 已切 Bunny 域名

- 前端房间列表 feed 显示 10 房间可观看

## 风险与回退

| 风险 | 缓解 |
|---|---|
| copy 推流时间戳/花屏异常 | PUSH_COPY 开关可随时切回重编码模式；阶段0已本地全链路测试 |
| 磁盘不足 | 阶段1前置核对，不足先扩盘 |
| Bunny m3u8 缓存过长致礼物切换延迟 | 缓存规则设 1-3s |
| 4 核直播中余量不足（SRS+php突发） | copy 推流后总负载 <2 核，预留充足；极端时 worker 挪 47（架构已参数化） |
| 全部 SQL 前 mysqldump；worker 不动 AI 电脑环境 | 可整体回退到现状 |
