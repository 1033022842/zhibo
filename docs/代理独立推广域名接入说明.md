# 代理独立推广域名接入说明（客户版）

> 适用场景：给代理分配一个独立推广域名，代理用该域名生成推广链接，客户从该域名进入并注册后，系统自动把注册用户归属到该代理。
>
> 文档中的 `【推广域名】`、`【站点】`、`【代理名称】` 请替换为实际信息。

---

## 一、整体流程

```
客户域名 DNS
   ↓ CNAME
Bunny CDN（ever-candy Pull Zone）
   ↓ 回源
站点源服务器
   ↓
后台「代理管理」只读展示
   ↓
代理在 /agent「专属域名」自助添加
   ↓
代理在 /agent 生成推广链接
   ↓
客户从域名进入并注册 → 自动归属代理
```

DNS 解析只是第一步。要让域名真正可用并正确归属代理，需要完成下面三部分：

| 事项 | 负责方 | 说明 |
|---|---|---|
| 1. 域名 DNS 解析 | 客户 | 把 `@` 和 `www` CNAME 到 Bunny |
| 2. Bunny 添加自定义域名 + SSL | 客户 / 运维 | 让 Bunny 认识这个域名并签发证书 |
| 3. 源站配置 | 我们 | 源站接受该域名、验收（域名由代理自己登记，总部不再分配） |

---

## 二、客户需要做的 3 件事

### 第 1 步：确认 DNS 解析

在域名 DNS 服务商处配置：

| 主机记录 | 记录类型 | 记录值 |
|---|---|---|
| `@` | CNAME | `ever-candy.b-cdn.net` |
| `www` | CNAME | `ever-candy.b-cdn.net` |

注意事项：

- **不要**把域名直接 A 记录到源站 IP，否则会绕过 CDN。
- 如果原来有 A 记录、AAAA 记录或其他 CNAME，需要先删除，避免冲突。
- `@` 和 `www` 建议都添加；如果只需要根域名，也要在申请时说明。
- DNS 生效通常需要几分钟到几小时，取决于服务商。

### 第 2 步：在 Bunny 添加自定义域名并申请证书

进入 Bunny 后台对应的 Pull Zone（`ever-candy`）：

1. 打开 **Hostnames / 自定义域名**。
2. 点击 **Add Custom Hostname**，依次添加：
   - `【推广域名】`
   - `www.【推广域名】`（如果需要）
3. 打开 **SSL**，为每个域名申请免费证书（Let's Encrypt）。
4. 等待证书状态变为 **Active / 已生效**。

因为 DNS 已经 CNAME 到 Bunny，证书验证通常会自动通过。如果一直处于 Pending，优先检查 DNS 是否已经生效。

### 第 3 步：确认回源和访问结果

在浏览器直接访问：

```
https://【推广域名】/
```

期望结果：

- 能正常打开站点；
- 证书有效，没有安全警告；
- **地址栏仍然是【推广域名】，不会跳到主域名**。

如果出现以下情况，请截图发我们：

- 打不开 / 证书错误；
- 404 / 502；
- 自动跳转到主域名（例如 `https://主域名/...`）。

> 重点：如果访问推广域名会 301 跳到主域名，代理域名的“直接访问归因”会失效，需要我们在源站调整跳转规则。

## 四、我们收到信息后会做什么

1. 在对应站点源站 Nginx 增加该域名的 `server_name` / 独立 server 配置；
2. 处理 HTTPS 证书和跳转规则，确保推广域名不会被跳回主域名；
3. 通知代理登录 `/agent` →「专属域名」自行添加该域名（总部代理管理只读展示，不再需要先在总后台分配）；
4. 验证代理端能生成该域名的推广链接；
5. 用一个测试账号完成注册归因验证。

## 五、验收标准

上线前请一起确认下面 7 项：

- [ ] `https://【推广域名】/` 返回 200，能正常打开站点
- [ ] 证书有效，无安全警告
- [ ] 访问推广域名不会 301 跳转到主域名
- [ ] 代理在 `/agent` →「专属域名」里已添加并显示这个域名
- [ ] 代理登录 `/agent` 创建链接时能选择这个域名
- [ ] 链接可以正常复制并打开
- [ ] 从该域名注册一个测试账号后，「代理数据」里该代理注册数 +1

## 六、常见问题

### 1. 域名打不开或证书一直 Pending

- 检查 DNS 是否已经生效：
  ```bash
  nslookup 【推广域名】
  ```
  应能看到 CNAME 指向 `ever-candy.b-cdn.net`。
- 检查 Bunny 是否已经添加该 Hostname。
- 检查域名是否有 CAA 记录限制了 Let's Encrypt。

### 2. 访问后跳到主域名

说明源站或 CDN 配置了统一跳转。把访问结果截图发我们，需要在源站给该域名单独放行，不能跳到主域名。

### 3. 页面 404 或 502

- 502：通常是回源地址或源站服务异常；
- 404：通常是源站没有识别该域名，或静态目录配置不对。
- 把地址栏 URL 和页面截图发我们排查。

### 4. 注册后代理数据没有增加

按顺序检查：

1. 代理是否已在 `/agent` →「专属域名」里添加该域名（顶级代理自助添加，不需要总后台分配）；
2. 访问时地址栏是否仍是推广域名（没有被跳走）；
3. 推广链接是否带 `?name=` 参数；
4. 注册账号是否为测试后新注册的账号。

### 5. 一个域名可以给多个代理吗？

不可以。一个专属域名只能归属一个代理；多个代理可以使用同一个主站域名下的不同推广链接。

---

## 七、注意事项

- 推广域名是代理的“门面”，建议使用与主站不同的独立域名或子域名。
- 不要把域名直接解析到源站 IP，也不要删除 CNAME。
- 域名分配给代理后，不要随意更换归属，否则历史数据仍停留在原代理名下。
- 上线前务必用测试账号走一遍完整注册流程，再交付给代理使用。
