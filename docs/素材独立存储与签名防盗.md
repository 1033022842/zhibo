# 素材独立存储 + 签名防盗链（运维说明）

> 目标：视频/图片素材从项目机剥离，集中存放在一台**带宽+存储**服务器；
> 对外只发**有时效的签名 URL**，源站不可直连，防盗链 / 防搬运 / 防风控扫素材。
> 推流仍在各项目自己机器（本项目不统一推流）。

---

## 一、总体结构

```
              ┌──────────────────────────────────────────┐
              │  存储服务器 155.103.194.69（Phoenix）     │
              │  4.9T ext4 (/mnt/storage)                │
              │  ┌────────┐   ┌──────────────────────┐   │
  写（项目机）│  │ MinIO  │◄──┤ nginx :443           │   │
  ────────────┼─►│ :9000  │   │  /s3/  写网关(密钥)   │   │
              │  └────────┘   │  /sec/ secure_link    │   │
  读（浏览器）│               │  /pub/ 公开缓存        │   │
  ────────────┼──────────────►│  MinIO 只监听 127.0.0.1│   │
              │               └──────────────────────┘   │
              └──────────────────────────────────────────┘
```

四个项目共用**同一个桶** `sugus-media`，各自占一个前缀：

```
sugus-media/
├── pub/<project>/covers/...          公开素材（不签名，可被 CDN 长缓存）
└── sec/<project>/chat_media/...      私有素材（必须带 ?e=&s= 签名）
```

`<project>` 取 `.env` 的 `MEDIA_PROJECT`：`sugus` / `hey` / `proj3` / `proj4`。

## 二、存储服务器

| 项 | 值 |
|---|---|
| 访问域名 | `https://155-103-194-69.sslip.io`（Let's Encrypt，2027-01 到期，certbot 自动续） |
| 数据盘 | `/dev/vdb1` → `/mnt/storage`（ext4，UUID 写进 fstab） |
| MinIO 数据 | `/mnt/storage/data`，容器 `minio`（chainguard 镜像，UID 65532） |
| 环境变量 | `/mnt/storage/etc/minio.env`（chmod 600） |
| 网关配置 | `/etc/nginx/sites-available/media`（仓库备份：`docs/storage-server-media.nginx.conf`） |
| 运维工具 | `/usr/local/bin/mc`（`mc alias` 已配 `local`） |
| 备份 | 项目机 `cron 17 3 * * *` 跑 `/root/deploy/backup_media.sh`（`mc mirror` 到 `/data/media_backup`） |

### 2.1 nginx 三个入口

| 路径 | 校验 | 用途 |
|---|---|---|
| `/sec/...` | `secure_link`：`md5($e$uri $SECRET)` | 私有素材，缺/错签名 403，过期 410 |
| `/pub/...` | 无 | 公开素材，`Cache-Control: public, max-age=604800` |
| `/s3/...` | 请求头 `X-Media-Key` | 项目机上传/列举网关，proxy 到 MinIO 并补 `/sugus-media` 前缀 |

> 9000 端口只监听 `127.0.0.1`，公网无法绕过 nginx。

### 2.2 密钥（三处必须一致）

| 用途 | 值 | 出现位置 |
|---|---|---|
| 签名密钥 | `SIGN_SECRET` | 存储 nginx `secure_link_md5` + 各项目 `.env` `MEDIA_SIGN_SECRET` |
| 写网关口令 | `MEDIA_GATEWAY_KEY` | 存储 nginx `map $http_x_media_key` + 各项目 `.env` `MEDIA_GATEWAY_KEY` |
| MinIO 账号 | `MINIO_ROOT_USER/PASSWORD` | 只在存储服务器；项目机通过 S3 签名使用 |

修改后：`systemctl reload nginx`（存储端）；项目机改 `.env` 后
`rm -rf php/runtime/*.php && systemctl reload php8.3-fpm`。

## 三、项目机改造点（PHP）

| 文件 | 作用 |
|---|---|
| `php/config/media.php` | 全部开关与参数（`MEDIA_*` → `media.*`） |
| `php/app/common/library/media/S3Client.php` | 纯 PHP SigV4（PUT/GET/HEAD/DELETE/List），无 composer 依赖 |
| `php/app/common/library/media/Media.php` | 路径映射、签名、上传、列举门面 |
| `php/app/common/library/upload/driver/S3.php` | 上传驱动（`STORAGE_ENABLED=1` 时自动启用） |
| `php/app/common/middleware/MediaUrlSigner.php` | **出参**：JSON/HTML 里 `/storage/` → 签名 URL |
| `php/app/common/middleware/MediaInputNormalizer.php` | **入参**：签名 URL → `/storage/`（后台保存不写死签名） |
| `php/app/command/MediaMigrate.php` | `php think media:migrate` 批量迁移 |

设计原则：**数据库永远只存 `/storage/xxx`**，签名只在输出时生成；
签名过期时间对齐 1 小时时间桶（`SIGN_BUCKET_SEC=3600`），同一小时内 URL 相同，缓存友好。

### 3.1 三个开关（按顺序打开）

| 开关 | 作用 | 打开前提 |
|---|---|---|
| `STORAGE_ENABLED` | 新上传落对象存储 | 素材已可写、桶可访问 |
| `ENABLED` | 输出换签名 URL | **全部历史素材已迁移完** |
| `MEDIA_ENDPOINT`（worker 侧） | worker 从存储服务器拉素材 | 同上 |

> 任一开关为 0 时，行为与改造前**完全一致**（回滚只需把开关改回 0 并 reload php-fpm）。

### 3.1.1 切换步骤（照抄执行）

```bash
cd /www/wwwroot/douyin/php
# ① 迁移全部素材（可重复执行，已传的会跳过）
php think media:migrate --run
# ② 抽查几个 URL 能在存储服务器拉到（见 6.4）
# ③ 开写路径
sed -i 's/^STORAGE_ENABLED = 0$/STORAGE_ENABLED = 1/' .env
# ④ 开读路径（签名）
sed -i 's/^ENABLED = 0$/ENABLED = 1/' .env
rm -rf runtime/*.php && systemctl reload php8.3-fpm
```

**⑤ 封掉项目机本地素材直读（防绕过签名）**

`ENABLED=1` 后前端已经全部走签名地址，项目机上的 `/storage/` 只剩兜底作用。
确认稳定后，把主站 nginx 里的这段改成 `return 403`：

```nginx
# 改前
location ^~ /storage/ { alias /www/wwwroot/douyin/php/public/storage/; expires 1h; }
# 改后（admin 域名 sugus.it.com 保留只读，主站域名封掉）
location ^~ /storage/ { return 403; }
```

> 后台预览图仍读本机（admin 域名），主站封掉后任何"猜路径"的直连都会被拦。

**⑥ 删本地素材（可选，确认稳定一周后）**

```bash
php think media:migrate --run --delete
```

### 3.2 迁移命令

```bash
cd /www/wwwroot/douyin/php
php think media:migrate                       # 预演（只统计）
php think media:migrate --run --dir=chat_media # 只迁一个目录
php think media:migrate --run                 # 全量上传
php think media:migrate --run --delete        # 上传后删本地（确认无误再执行）
```

已存在的对象会跳过（`HEAD` 命中），可重复执行。

### 3.3 上传链路

```
浏览器 → 项目机 nginx/PHP（512M 限制）→ Upload(S3 驱动) → 存储服务器 /s3/ → MinIO
```

项目机**只做中转**，不落盘长期保存；`ba_attachment` 里记 `storage=s3`、`url=/storage/xxx`。

## 四、CDN（下一步）

当前对外地址是 `https://155-103-194-69.sslip.io`（IP 直连 + Let's Encrypt）。
接入 CDN 时**只需要换 `MEDIA_ENDPOINT`**，签名逻辑不变：

1. Bunny 建 Pull Zone，Origin 填 `https://155-103-194-69.sslip.io`
2. 回源保留 query string（`?e=&s=`）
3. 缓存规则：`/pub/*` 缓存 7 天；`/sec/*` **缓存 1 小时**（与签名时间桶一致）
4. 项目机 `.env` 改 `ENDPOINT = https://<pull-zone>.b-cdn.net`
5. 存储服务器防火墙只允许 Bunny 回源 IP 访问 443（`/etc/nginx/bunny_realip.conf` 有现成方案）

> 签名 URL 在 CDN 边缘直接命中；过期后由源站返回 410，不会产生回源风暴。

## 五、worker（推流）改造

`services/channel-worker/python/worker.py` 新增：`MEDIA_ENDPOINT` / `MEDIA_SIGN_SECRET` /
`MEDIA_PROJECT` / `MEDIA_CACHE_DIR`。

`_resolve_path()` 遇到 `/storage/xxx` 时：
1. 本地缓存命中（`runtime/media_cache/<rel>`）→ 直接返回；
2. 否则按签名规则拉取到缓存再返回；
3. `MEDIA_ENDPOINT` 为空 → 行为不变（读本机 `php/public/storage`）。

## 六、常见操作

### 6.1 新增一个项目（第 4 个站）

1. 存储服务器：无需新建桶，直接复用 —— 只需给该项目准备两个密钥（可复用现有一组）。
2. 项目机 `.env`：
   ```ini
   [MEDIA]
   ENABLED = 0
   STORAGE_ENABLED = 0
   ENDPOINT = https://155-103-194-69.sslip.io
   PROJECT = proj4          ; ← 唯一区别
   SIGN_SECRET = <同上>
   S3_ENDPOINT = https://155-103-194-69.sslip.io/s3
   BUCKET = sugus-media
   ACCESS_KEY = minioadmin
   SECRET_KEY = <同上>
   GATEWAY_KEY = <同上>
   ```
3. 部署代码 → `php think media:migrate --run` 迁本项目素材 → 依次开
   `STORAGE_ENABLED=1`、`ENABLED=1`。

### 6.2 扩容磁盘

存储服务器买的是"加盘"型：新盘挂到 `/mnt/storage2`，把新素材前缀软链进去，或
用 `mc mirror` 把冷数据搬走；MinIO 单盘模式不支持在线扩容，扩容时按"新盘 → 后台
配置 `s3_endpoint` 不变、`bucket` 分桶"的方式滚动迁移。

### 6.3 备份

建议在存储服务器加一条 crontab：

```bash
# 每天 03:17 把 pub/ 同步到另一台机（私有大文件按需）
0 3 * * * mc mirror --overwrite local/sugus-media/pub backup/sugus-media-pub
```

### 6.4 验证清单（每次改动后跑）

```bash
# 1. 公开资源
curl -sI https://155-103-194-69.sslip.io/pub/sugus/covers/xxx.webp | head -1   # 200
# 2. 私有资源无签名
curl -s -o /dev/null -w '%{http_code}\n' https://155-103-194-69.sslip.io/sec/sugus/chat_media/home-1/1.jpg  # 403
# 3. 接口出签名
curl -s 'http://127.0.0.1/api/live/chatGifts' | head -c 200                     # 应含 ?e=...&s=...
# 4. 签出的 URL 可下载
curl -s -o /dev/null -w '%{http_code}\n' '<上一步的 URL>'                        # 200
```

## 七、回滚

| 现象 | 处理 |
|---|---|
| 图片/视频 404 | 把 `ENABLED` 改回 `0` → `rm -rf php/runtime/*.php` → reload php-fpm（本地文件仍在，立刻恢复） |
| 新上传失败 | `STORAGE_ENABLED=0` 即可回本地上传 |
| worker 拉不到素材 | 清空 `MEDIA_ENDPOINT` 重启 worker（回本地路径） |
| 存储服务器故障 | 项目机 `ENABLED=0` 即恢复本机；未迁移完的文件本来就还在本地 |

> 因此 `media:migrate --delete` 只在**确认线上稳定运行一周**后再执行。
