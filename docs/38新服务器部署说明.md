**决策**：新服务器不跑推流（避免跨境链路上行瓶颈），直播 HLS 直接复用 172 生产用的 Bunny CDN。


关键改动：
| 项 | 值 |
|---|---|
| `php/.env` | `[AI] HLS_CDN_DOMAIN = https://ever-candy.b-cdn.net`（顶层 `SRS_API_HOST=172.81.98.55`、`SRS_API_PORT=1986`） |

| crontab | `* * * * * ... runuser -u www-data -- php think presence:sync`（每分钟） |
| live-worker@{1,17-26} | 已 `stop` + `disable` |

⚠️ 两个必知点：
1. **在播判定依赖 `lp_room_state_snapshot.current_state='public_live'`**（`feedLive` INNER JOIN）。
   停推流后本机 SRS 钩子不再触发，该表会空 → 前台全部离线。故用 `presence:sync` 从 172 同步。
2. **CDN 回源 172 有中国大陆屏蔽**：国内直连 `ever-candy.b-cdn.net` 返回 403（设计行为），
   需海外/VPN 才能播放。若需国内可看，得给 38 单独加一个不屏蔽的回源 CDN。
