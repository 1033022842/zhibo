# 50 条预设提示词改写需求书（交给外部改写用）

> 版本：v1.0 ｜ 2026-10-28
> 目标读者：负责改写提示词的模型/人员
> 背景：现有 50 条提示词是「特定场景脚本」，与用户上传的任意图片不匹配，导致出片质量崩溃。
> 本次改写把它们变成「**图像条件化的运动修饰器**」——任何一张图都能用。

---

## 一、必须先理解的约束（这条决定改写成败）

**I2VA（图生视频）不是「用这张图生成新画面」，而是「让这张图这一帧动起来」。**

模型把输入图当作视频的**第 0 帧**，只能在这个构图上延续运动。它**没有能力**把「站立半身像」变成「俯视特写」，也**没有能力**把单人变成双人。

### 实测证据（我们自己的数据，不是推测）

| 提示词里明确要求 | 实际结果 |
|---|---|
| `Single female character only`（只有一名女性） | 画面出现背景第三人、第二个男人 |
| `Hands and fingers remain anatomically correct with five fingers each` | 手部生成 6–7 根手指 |
| `Private Cinema missionary`（含影院场景描述） | 生成床上近景，影院消失 |
| `From a first-person POV looking down, she kneels and takes it deep` | 输入是站立微笑半身像 → 0.7 秒硬跳变、动作扭曲 |

**结论：模型对硬性约束的遵循度很低，对大幅改变构图/姿势的要求几乎无响应。**

所以改写的核心原则是：**只描述「在这张图上能自然发生的运动」，绝不要求改变构图、机位、人数、场景。**

## 二、改写的核心思路

### 2.1 角色转变

| | 旧（场景脚本） | 新（运动修饰器） |
|---|---|---|
| 描述对象 | 一个完整的画面：「俯视 POV，她跪下深喉」 | 一个运动过程：「镜头缓慢推近，她呼吸加深」 |
| 前提假设 | 假定用户图就是那个镜头 | **不假定任何构图**，只说「在这个构图上加什么运动」 |
| 适配范围 | 只有构图匹配的图能用 | 任何图都能用 |

### 2.2 五个正交维度

每条预设 = 一个维度组合，**不是**一个故事：

| 维度 | 可选值 | 说明 |
|---|---|---|
| **镜头运动** | `static` / `slow_push_in` / `slow_pull_out` / `gentle_orbit` / `handheld_sway` / `low_angle_rise` | 只描述摄像机怎么动，不描述被摄对象 |
| **动作幅度** | `subtle` / `moderate` / `intense` | 轻微（呼吸、转头）→ 中等（肢体移动）→ 强烈（大幅律动） |
| **情绪** | `shy` / `seductive` / `longing` / `ecstatic` / `playful` / `detached` | 表情与氛围 |
| **聚焦** | `face` / `upper_body` / `full_body` / `detail` | 视觉重心，**不改变实际构图，只是强调** |
| **着装动作** | `keep` / `tease` / `remove_partial` / `remove_all` | 只在用户图「衣着状态」允许时生效 |

### 2.3 关键：用「条件句」代替「强制句」

不要写「她跪下」（要求改姿势），要写「**如果她的姿态允许**，她缓慢下沉」。

推荐句式：

```
Maintain the composition, camera angle, subject count and background of <Picture 1>.
[运动描述] should happen within this existing framing.
```

**必须包含的约束句**（每条都要有）：

```
Maintain the exact composition, camera angle, framing distance, subject count
and background of <Picture 1>. Do not add any person, limb or object not
present in <Picture 1>. Do not change her pose drastically.
```

## 三、输出格式（必须严格遵守）

### 3.1 结构

每条预设输出**四段**，用空行分隔，顺序固定：

```
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.

integrated_multimodal_description: [Shot 1] Live-action, photorealistic. <主体描述> <运动描述> <镜头描述> <约束句>

overall_soundscape: <环境音与身体音>

non_diegetic_music: N/A
```

### 3.2 长度限制

| 字段 | 上限 | 当前实测 |
|---|---|---|
| 全文（四段合计） | **900 字符**（硬上限） | 当前 618–801 |
| `integrated_multimodal_description` | 650 字符 | 当前 383–587 |

**超长会被数据库截断，务必控制。**

### 3.3 `integrated_multimodal_description` 的固定写法

必须按这个顺序，缺一不可：

```
[Shot 1] Live-action, photorealistic. The woman shown in <Picture 1> remains
consistent in appearance, clothing and initial pose throughout. <运动描述>.
<镜头描述>. Maintain the exact composition, camera angle, framing distance and
background of <Picture 1>; do not add any person or object not present in
<Picture 1>. Hands and fingers remain anatomically correct with five fingers
each; facial features stay consistent and natural.
```

其中两段是**每条都一样的固定模板**，只有 `<运动描述>` 和 `<镜头描述>` 两条要变。

## 四、50 条的具体分布要求

### 4.1 覆盖矩阵

50 条要覆盖五个维度的组合，避免全是一个调性。建议分布：

| 聚焦 | face 15 / upper_body 15 / full_body 15 / detail 5 |
| 着装动作 | keep 25 / tease 12 / remove_partial 8 / remove_all 5 |

## 五、每条预设要交付的字段

按下面的格式，**50 条一次性给出**（JSON 数组，不要表格）：

```json
[
  {
    "code": "gs-01",
    "title": "Slow Surrender",
    "category": "blowjob",
    "motion": {
      "camera": "slow_push_in",
      "intensity": "subtle",
      "emotion": "shy",
      "focus": "face",
      "wardrobe": "keep"
    },
    "requires": {
      "min_people": 1,
      "max_people": 1,
      "framing": ["upper_body", "full_body"],
      "wardrobe": ["clothed", "partially_clothed"],
      "orientation": ["front", "three_quarter"]
    },
    "prompt": "For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.\n\nintegrated_multimodal_description: [Shot 1] Live-action, photorealistic. The woman shown in <Picture 1> remains consistent in appearance, clothing and initial pose throughout. She holds eye contact while her breathing deepens and her eyelids lower slowly, lips parting slightly. The camera pushes in slowly with small amplitude. Maintain the exact composition, camera angle, framing distance and background of <Picture 1>; do not add any person or object not present in <Picture 1>. Hands and fingers remain anatomically correct with five fingers each; facial features stay consistent and natural.\n\noverall_soundscape: Quiet room ambience, soft breathing, faint fabric rustle.\n\nnon_diegetic_music: N/A"
  }
]
```

### 字段说明

| 字段 | 必填 | 约束 |
|---|---|---|
| `code` | 是 | 必须保持 `gs-01`..`gs-50`，不能改（数据库主键） |
| `title` | 是 | ≤120 字符，2–4 词，不含机位词 |
| `category` | 是 | 沿用原分类：`blowjob`/`cowgirl`/`doggy`/`other`/`cumshot`/`solo` |
| `motion` | 是 | 五个维度，取值必须来自第 2.2 节的枚举 |
| `requires` | 是 | 兼容性约束，见下 |
| `prompt` | 是 | 四段结构，全文 ≤900 字符 |

### `requires` 的含义（决定这条对用户图是否可用）

| 键 | 类型 | 含义 |
|---|---|---|
| `min_people` / `max_people` | int | 图中人数范围（1 = 单人，1–2 = 允许双人） |
| `framing` | 数组 | 需要的镜头距离：`face` / `upper_body` / `full_body` |
| `wardrobe` | 数组 | 需要的着装状态：`clothed` / `partially_clothed` / `nude` |
| `orientation` | 数组 | 人物朝向：`front` / `three_quarter` / `side` / `back` |

**填写原则：宁可宽松，不要过严。** 因为用户图匹配不上时，前端会置灰该卡片，太严会让可用选项太少。

## 六、写作质量要求

### 6.1 必须做到

1. **每条只描述 1–2 个运动**，不要堆叠多个动作（模型处理不了）
2. **镜头描述与运动描述分离**，不要混在一句里
3. **不使用具体身体部位的特写要求**（如「close-up on her throat」），因为输入图可能没有那个构图
4. **情绪词具体化**：不要写 `sexy`，要写 `her eyelids lower, lips part slightly, breathing deepens`
5. **环境音要与运动匹配**，不要写画面里不存在的东西（如输入图是室内却写「窗外城市车流」）

### 6.2 绝对禁止

| 禁止项 | 原因 |
|---|---|
| 要求改变机位（"from a first-person POV looking down"） | 输入图无法变成那个机位 |
| 要求改变人数（"a man's hand enters the frame"） | 会在画面里凭空生成第二人 |
| 描述参考图中不存在的场景（"in a luxury hotel room"） | 会覆盖掉原背景 |
| 假设特定姿势（"she is bent over the counter"） | 输入图不是那个姿势就无法执行 |
| 使用 `[Shot 2]`、`[Shot 3]` 多镜头 | 我们的时长只有 8 秒，单镜头 |
| 超过 900 字符 | 数据库截断 |
